# voice_lines_vox

Working data for the Hila (rb21) voice-line replacement mod: Hila's PD2 lines mapped onto
Miranda Lawson voice clips from `references/Голос Лоусон.7z`.

## Slot rule: Call vs Follow

- `Call <Name>` (rb21 `CH_Name`, summon a teammate) → **"Hey, you."**
  Slot `call_teammate.hey_you`. A named callout ("Hey, Sokol!", "Bonnie.") becomes generic
  because Miranda does not know the heisters' names.
- `Follow` / `On me.` (rb21 squad-move) → **"On me."**
  Slot `move.on_me`. Follow keeps the on-me phrasing, so Call must not use it.

## Files

| File | Role |
| --- | --- |
| `hila_regular_vox.csv` | Source list of Hila's PD2 lines (ID / speech / category). Provenance only. |
| `hila_call_hey_you.csv` | Per-ID replacement decision (original → new speech + note). Legend for the Call/Follow split. |
| `miranda_lawson/miranda_transcripts_corrected.csv` | Miranda transcripts used for matching (whisper text + hand corrections). |
| `miranda_lawson/ogg_phrase_splits.csv` | Per-ogg phrase boundaries used when cutting barks. |
| `miranda_lawson/hila_to_miranda_mapping.csv` | Hila ID → Miranda file hint / suggested line. |
| `miranda_lawson/slot_picks.csv` | **Hand-curated clip per slot** (file + time range, or a `splits` splice list). Both tools prefer these rows over the heuristic; edit here to retune a bark. |
| `miranda_lawson/hila_intent_cuts.csv` | The authoritative Hila ID → intent slot → `cut_line` table (`build_hila_voice_mod.py` reads this). |
| `miranda_lawson/hila_intent_fit.csv` | Generated by `tools/fit_hila_intents.py`: chosen clip + score per slot. |
| `miranda_lawson/hila_slot_pieces.csv` | Generated: the exact ogg/time range cut for each slot. |

## Regenerate

```bash
python3 tools/fit_hila_intents.py        # hila_intent_fit.csv + hila_slot_pieces.csv
python3 tools/build_hila_voice_mod.py    # mod zip (needs py7zr + ffmpeg)
```

## Package & install

The zip is a BeardLib **SoundsModule** mod: `mods/Miranda Lawson VO over Hila/` with `main.xml`
(prefix `rb21`), `mod.txt`, `README.txt` and `sounds/*.ogg`. SuperBLT (for the XAudio OGG API) and
BeardLib 5.x are hard requirements - see
[`docs/pd2-voice-mod-install.md`](../docs/pd2-voice-mod-install.md) for the full packaging contract,
install/uninstall steps and the in-game verification recipe (BeardLib's *Log Sounds* option).

> **Open issue (id key space).** `main.xml` is currently keyed on PD2's numeric voice-line ids
> (`712675`, `1149328`, …). PD2 posts heister barks by **event name** (`f11e_plu`, `g18`,
> `f30x_any`, …) with the speaker chosen by the `robber` switch (`rb21` = Hila), so as built the pack
> loads but will not replace anything until the ids are re-keyed. Everything else about the package
> (layout, module, prefix, OGG paths, stop ids) is correct; the re-key is a build-side mapping change
> only. See section 4 of the install doc.

## Rules the tools enforce

- **No names.** No replacement clip may say "Shepard", "Commander" or "Commando" - `fit_hila_intents.py`
  filters those transcripts out and every `slot_picks.csv` window is trimmed before the name.
- **Level matching.** Each bark is peak-matched to -1.5 dBFS (max +12 dB boost) so quiet takes
  such as "Captain" are not swallowed next to loud ones; `slot_to_ogg.csv` records the gain applied.
- **Reproducible builds.** Every ffmpeg encode runs with `-fflags +bitexact`, so the same picks
  always produce the same clip bytes and the same `dist/Hila/*.sha256`.
- **Cuts land on silence.** Windows come from `silencedetect` breakpoints plus syllable-rate
  estimates, so a trim takes the pause that surrounds the dropped word. `splits` in
  `slot_picks.csv` splices two ranges when the unwanted word sits mid-phrase (e.g. tech.drilling
  drops "down" from "we can cut down through").

## Known gaps in the source pack

Miranda has no line for several PD2 barks; those slots keep the closest available take:

- `drop.body` ("Bag") - the pack has no "bag" at all, so it says "Those bodies,".
- `cop.hands` / `cop.drop` ("Hands up" / "Drop it") - no police vocabulary; they use "Stop" and "Don't".
- `tech.fix` ("Fix it") - nearest line is "You'll have to do it.".
- `call_teammate.hey_you` ("Hey, you") - no "hey" anywhere, so it says "you take point.".

Re-cut those slots (`slot_picks.csv`) if a matching take is ever recorded.

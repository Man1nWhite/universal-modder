# Source and Reference Archives

Character archives, reference PAYDAY 2 mods, voice packs and community sheets the build pipelines
read. Six folders, grouped by what reads them; every tracked file is in one of them. The packaged
downloads are grouped under `dist/`, and previews with their source provenance are in the
[render index](../docs/renders/README.md).

| Folder | Files | Size | What it is |
|---|---|---|---|
| `characters/` | 4 | 30.5 MB | the character sources the LAS and head packs are cut from |
| `templates/` | 6 | 45.4 MB | reference mods supplying skeletons, heister units and material paths |
| `textures/` | 3 | 12.8 MB | the supplied textures and the one reference texture mod |
| `honoka/` | 31 | 17.4 MB | the DOAXVV export, this repo's own glTF of it, and the DDS dump |
| `voice/` | 7 | 65.1 MB | the packs the three VO routes copy containers, tables and clips from |
| `sheets/` | 7 | 2.3 MB | the community voice-line sheets, held as the full exports |

This directory is a provenance shelf as much as an input shelf: nothing in it is generated by this
repository, and every pack in `dist/` is rebuilt from it, so a file that leaves the tree leaves the
record. The audit that sorted it — what is read, what was removed on 2026-11-26 and why, and what a
move costs — is `docs/audits/2026-11-26-references-inventory.md`.

## `sheets/` — 2.3 MB

The community voice-line sheets, downloaded rather than paged through (the API only serves them a
page at a time), and imported in full on 2026-11-26 (D81): `voice_lines_vox/sheets/` holds the
normalized tables and `voice_lines_vox/sheets/COVERAGE.md` says what each tab declares against what
it holds. `make -sC tools/pd2-las voices_sheets SHEET="references/sheets/<file>.csv" TAB=<tab>`
imports one again. The exports are inputs, not leftovers: they are what makes the import reproducible
offline.

## Notes on specific inputs

**Game input (Old Hoxton / Arivus head pack):** `dist/Arivus/Arivus_over_Hoxton.zip` replaces the
`g_head_old_hoxton` drawable of the **shared suit model**, built from `templates/npc_criminals_suit_1.7z` — the
vanilla `units/payday2/characters/npc_criminals_suit_1/` folder (`npc_criminals_suit_1.model` = cooked
DODB container, `npc_criminals_suit_menu_1.model` (byte-identical to the heist one), the `.object`s and
`mtr_old_hoxton[_cc].material_config`), user-extracted from `assets/bundle_db_blb` with DieselBundleViewer
and supplied on 2026-11-24. `tools/pd2-las/diesel_model.py` reads DODB containers and cooked geometry
channels (packed UByte4N normals/UV directions, Half2 UVs); the patched models are written back in the
legacy container the modding ecosystem ships.

**Removed source inputs:** the Skyrim source archives `1.zip` through `5.zip` were deleted from the
repository on 2026-11-04, after the Skyrim outfit port was cancelled, and the tools that read them on
2026-11-13 (`docs/pd2-las/DECISIONS.md`, D33). Do not fetch or republish the archives unless the user
explicitly reopens the work. On 2026-11-26 the same sweep removed four files that nothing read —
`Honoka/location` (a `Location$` shell artifact), a duplicate of `voice_lines_vox/hila_regular_vox.csv`,
the superseded first Arivus atlas `old_hoxton_head_df.dds` (in git history) and the retired `Honoko4`
suit diffuse `Tex_07(L_7) 2.dds` — and moved everything else into the six folders above.

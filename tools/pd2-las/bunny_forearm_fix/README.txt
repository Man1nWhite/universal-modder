OfficeSuite over Bunny - installation

1. Copy "OfficeSuite over Bunny" into PAYDAY 2/assets/mod_overrides/.
2. Copy the folder "OfficeSuite Bunny Forearm Fix" inside that folder into
   PAYDAY 2/mods/. SuperBLT is required for this companion hook.
3. Restart the game. Select Hop to It and your preferred gloves.

The hook disables the separate vanilla forearm adapter for Hop to It only;
it does not replace the gloves or remove OfficeSuite's own forearm skin.
Remove the companion from mods/ if you revert to the vanilla Bunny outfit.
Do not install the OfficeSuite LAS outfit at the same time as a substitute for
this native replacement. Other mods changing the Bunny glove adapter may conflict.
